## 🧠 Overview

ERA is a bundle of one-knob audio repair plug-ins for video editors: each module targets a single problem such as background noise, room reverb, sibilance or a thin voice, and exposes a single amount control inside the host.

On a Windows machine it runs as a plug-in suite that loads inside Adobe Premiere Pro, Adobe Audition. Typical use is one-knob audio repair plug-ins work on local files, so the application does not need a subscription or a cloud project to open and save documents.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🔇 Noise Remover | Suppresses steady background noise with one amount control and a low/high split. |
| 🏛️ Reverb Remover | Reduces room reflections without gating the tail of the voice. |
| 🎙️ De-Esser | Tames sibilance on close-miked speech. |
| 🔊 Voice Deepener | Adds body to thin dialogue recorded on lavalier microphones. |
| 🎚️ Level Matching | Keeps perceived loudness consistent between clips. |
| 🧩 Host Chain | Modules stack in the host audio chain in any order and stay individually bypassable. |

## Additional Information for Windows Users

Settings created in Accusonus ERA are stored in the plug-in's own preset folder, so a reinstall keeps user presets and replaces only program files.

Removing the plug-in goes through the host application's plug-in manager or the Windows uninstall entry, depending on how it was registered.
